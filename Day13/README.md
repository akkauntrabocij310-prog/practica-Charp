# GradeBook — WPF (.NET Framework 4.8)

## Структура проекта

```
GradeBook/
├── App.xaml / App.xaml.cs          — точка входа приложения
├── Models/
│   └── Grade.cs                    — модель данных (INotifyPropertyChanged)
├── Commands/
│   ├── RelayCommand.cs             — базовая реализация ICommand
│   ├── AddGradeCommand.cs          — открывает диалог добавления
│   ├── EditGradeCommand.cs         — открывает диалог редактирования
│   └── DeleteGradeCommand.cs       — удаляет с подтверждением
├── ViewModels/
│   └── MainViewModel.cs            — главная ViewModel (MVVM)
└── Views/
    ├── MainWindow.xaml/.cs         — главное окно
    └── GradeDialog.xaml/.cs        — диалог добавления/редактирования
```

## Возможности

| Действие              | Меню                      | Кнопка на панели | Горячая клавиша |
|-----------------------|---------------------------|------------------|-----------------|
| Добавить оценку       | Оценки → Добавить оценку  | ➕ Добавить       | **Ctrl+N**      |
| Редактировать оценку  | Оценки → Редактировать    | ✏️ Редактировать | **Ctrl+E**      |
| Удалить оценку        | Оценки → Удалить          | 🗑️ Удалить       | **Del**         |
| Двойной клик по строке| —                         | —                | Редактировать   |

## Команды

- **AddGradeCommand** — всегда активна, открывает `GradeDialog` для новой записи
- **EditGradeCommand** — активна только при выбранной строке, передаёт копию объекта
- **DeleteGradeCommand** — активна только при выбранной строке, показывает `MessageBox` с подтверждением

## Как открыть

1. Откройте `GradeBook.csproj` в **Visual Studio 2019/2022**
2. Убедитесь, что установлен **.NET Framework 4.8**
3. **Ctrl+F5** — запуск

## Паттерны

- **MVVM** — View не знает о логике, ViewModel не знает о View
- **ICommand** — все действия реализованы через команды
- **INotifyPropertyChanged** — автоматическое обновление UI
- **CanExecute** — кнопки редактирования и удаления неактивны без выбора строки
